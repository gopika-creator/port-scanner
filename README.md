# Port Scanner

## Overview

Port Scanner is a Python-based cybersecurity tool that identifies open TCP ports on a target host. The application uses socket programming to attempt connections to ports and determine which services are accessible.

## Features

- Scan ports 1–1024
- Detect open TCP ports
- Supports IP addresses and hostnames
- Fast and lightweight
- Command-line interface

## Technologies Used

- Python 3
- Socket Programming

## How to Run

```bash
python main.py
